# Microcontroller Mini Project — Smart Fan Controller

มินิโปรเจกต์ระบบควบคุมพัดลมอัจฉริยะ พัฒนาด้วยภาษา MicroPython บนบอร์ดไมโครคอนโทรลเลอร์

ระบบสามารถอ่านค่าสภาพแวดล้อมเพื่อปรับความเร็วรอบพัดลมอัตโนมัติ หรือควบคุมด้วยตนเองผ่านปุ่มกด พร้อมทั้งแสดงสถานะและบันทึก Log การทำงาน

## ฟังก์ชันการทำงาน

- **วัดอุณหภูมิและความชื้น:** อ่านค่าจากเซนเซอร์ DHT22 แบบ Real-time
- **แสดงผลข้อมูล:** แสดงอุณหภูมิ ความชื้น เวลา และสถานะระบบผ่านจอ LCD (I2C Interface)
- **นาฬิกาเวลาจริง:** ดึงเวลาจริงจากชิป RTC DS3231
- **แป้นพิมพ์ควบคุม:** รับคำสั่งตั้งค่าและเลือกโหมดการทำงานผ่าน Keypad Matrix 4×4
- **ขับมอเตอร์พัดลม:** ควบคุมความเร็วรอบและทิศทางมอเตอร์ด้วยสัญญาณ PWM (Pulse Width Modulation)
- **บันทึกข้อมูล:** บันทึกประวัติและ Log ข้อมูลลงไฟล์ `data.txt`

## การเชื่อมต่อขาอุปกรณ์ (Pinout)

| อุปกรณ์ | ขา GPIO | รายละเอียดการเชื่อมต่อ |
|---|---|---|
| DHT22 Sensor | GPIO 18 | สัญญาณข้อมูล (Data) |
| I2C LCD Display | GPIO 21 (SDA), GPIO 22 (SCL) | การสื่อสาร I2C |
| Keypad Rows | GPIO 12, 13, 14, 15 | แถวแนวนอน (Rows) |
| Keypad Columns | GPIO 26, 27, 32, 33 | แถวแนวตั้ง (Columns) |
| Motor Driver / PWM | GPIO 5 (Enable), GPIO 16, 17 (IN1, IN2) | ควบคุมความเร็วและทิศทาง |

## วิธีการเปิดใช้งาน

1. เชื่อมต่อบอร์ดไมโครคอนโทรลเลอร์เข้ากับคอมพิวเตอร์ และเปิดโปรแกรม **Thonny IDE**
2. ติดตั้งไลบรารีที่จำเป็นบนบอร์ด (`lcd_api.py`, `i2c_lcd.py`)
3. เปิดไฟล์ `main.py` แล้วกด Run เพื่อเริ่มการทำงาน
