# โครงงานที่ 2: เครื่องควบคุมหลอดไฟตามการเคลื่อนไหวแบบตั้งเวลาผ่านเว็บไซด์และบลูทูธ (Smart Motion-Activated Light Controller)

โครงงานระบบควบคุมไฟส่องสว่างอัจฉริยะ ทำงานร่วมกันระหว่างการตรวจจับความเคลื่อนไหว (PIR Sensor) และตัวตั้งเวลา (Dual Timers) พร้อมรองรับการควบคุมทางไกลผ่านระบบ IoT (Firebase Realtime Database) และบลูทูธ (BLE)

## คุณสมบัติเด่นของระบบ
- **การตรวจจับความเคลื่อนไหว (PIR Motion Detection):** ใช้เซนเซอร์ HC-SR501 ตรวจจับบุคคล เมื่ออยู่ในช่วงเวลาตั้งเวลา หลอดไฟจะติดเฉพาะเมื่อมีคนเคลื่อนไหว และดับอัตโนมัติเมื่อไม่มีการเคลื่อนไหว
- **การตั้งเวลา 2 ช่วงเวลา (Dual-Timer Scheduling):** กำหนดช่วงเวลาเปิด-ปิดอัตโนมัติ 2 ช่วงเวลาอิสระผ่าน RTC DS3231
- **การควบคุมไร้สาย 3 ทาง (Multi-interface Control):**
  1. คีย์แพ็ด 4x4 และหน้าจอ 16x2 I2C LCD
  2. บลูทูธพลังงานต่ำ (BLE UART Service UUID: `6E400001-B5A3-F393-E0A9-E50E24DCCA9E`)
  3. เว็บแดชบอร์ด Single Page Application เชื่อมต่อ Firebase Realtime Database
- **สถาปัตยกรรมมัลติเธรด (Multithreading):** ใช้ `_thread.start_new_thread()` แยกงานเน็ตเวิร์ก Firebase ออกจากลูปตรวจจับเซนเซอร์
- **การบันทึกสถานะถาวร:** บันทึกการตั้งค่าลงในไฟล์ `data.json` บนบอร์ด

## ผังวงจรและการเชื่อมต่อพิน (Pinout)

![ผังวงจรควบคุมหลอดไฟ](../../docs/images/motion-light/light-circuit-schematic.png)

| อุปกรณ์ | ขาสัญญาณ | ขาบอร์ด ESP32 |
|---|---|---|
| PIR Motion Sensor (HC-SR501) | OUT | GPIO 19 |
| Light Bulb / Relay LED | IN | GPIO 25 |
| DS3231 RTC | SDA / SCL | GPIO 21 / GPIO 22 |
| I2C LCD 16x2 | SDA / SCL | GPIO 21 / GPIO 22 |
| 4x4 Matrix Keypad | R1, R2, R3, R4 | GPIO 4, 5, 12, 13 |
| 4x4 Matrix Keypad | C1, C2, C3, C4 | GPIO 14, 15, 32, 33 |

## ตารางฟังก์ชันคำสั่ง Keypad (10 Functions)

กดปุ่ม `*` ตามด้วยหมายเลขฟังก์ชัน และยืนยันด้วย `#`:
- `*1#`: ตั้งเวลาปัจจุบัน (HH:MM:SS)
- `*2#`: แสดงสถานะการเคลื่อนไหว (Detect / Normal)
- `*3#`: ปิดไทม์เมอร์ (TIMER OFF)
- `*4#`: เปิดไทม์เมอร์ (TIMER ON)
- `*5#`: ตั้งเวลาเริ่มช่วงที่ 1
- `*6#`: ตั้งเวลาหยุดช่วงที่ 1
- `*7#`: แสดงช่วงเวลาที่ 1 บนจอ LCD
- `*8#`: ตั้งเวลาเริ่มช่วงที่ 2
- `*9#`: ตั้งเวลาหยุดช่วงที่ 2
- `*10#`: แสดงช่วงเวลาที่ 2 บนจอ LCD

## การใช้งานเว็บแดชบอร์ด (Web Dashboard)

ไฟล์ `web/index.html` ออกแบบมาสำหรับมอนิเตอร์และสั่งการระบบผ่านอินเทอร์เน็ต:
1. แสดงสถานะเวลาของบอร์ด (Device Time) แบบ Real-time
2. แสดงสถานะการตรวจจับความเคลื่อนไหว (ตรวจพบการเคลื่อนไหว / ปกติ)
3. สวิตช์ควบคุมไฟ Manual (พร้อมระบบ Safety Lock ป้องกันการเปิดทับซ้อนเมื่อ Timer ทำงาน)
4. ฟอร์มตั้งเวลาของบอร์ดและตั้งช่วงเวลา Timer 1 / Timer 2 ผ่านระบบคลาวด์ Firebase
